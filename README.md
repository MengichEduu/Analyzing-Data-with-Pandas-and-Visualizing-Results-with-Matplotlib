This repository contains solutions and answers to the tasks outlined below, demonstrating data loading, exploration, analysis, and visualization using Python and pandas.

## Tasks Covered

### Task 1: Load and Explore the Dataset
- Loaded a dataset in CSV format using pandas.
- Displayed the first few rows with `.head()` for inspection.
- Explored data structure by checking data types and missing values.
- Cleaned the dataset by handling missing values (filling or dropping).

### Task 2: Basic Data Analysis
- Calculated basic statistics (mean, median, std, etc.) for numerical columns with `.describe()`.
- Performed groupings on categorical columns (e.g., species, region) and computed mean values for numerical columns.
- Identified patterns and interesting insights from the analysis.

### Task 3: Data Visualization
- Created four different visualizations:
  - Line chart showing trends over time (e.g., sales over months).
  - Bar chart comparing a numerical value across categories (e.g., average petal length per species).
  - Histogram illustrating the distribution of a numerical column.
  - Scatter plot depicting relationships between two numerical variables (e.g., sepal length vs. petal length).

All plots are customized with titles, axis labels, and legends to enhance clarity.
